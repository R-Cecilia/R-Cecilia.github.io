欢迎来到这本学习笔记。

这本笔记记录 Git 版本控制的基本操作，用于整理日常开发中对仓库、提交和历史版本的管理方法。

## 学习路线

先熟悉仓库、提交和状态检查，再练习分支开发与合并，随后学习提交历史的调整，最后掌握远程仓库的推送、克隆与拉取。

1. [Git 基础：仓库、提交与状态检查]({{< relref "01-basics.md" >}})
2. [Git 分支：创建、开发与合并]({{< relref "02-branches.md" >}})
3. [Git 历史：回溯、修改与整理提交]({{< relref "03-history.md" >}})
4. [Git 远程协作：推送、克隆与拉取]({{< relref "04-remotes.md" >}})

## 开始之前

建议在单独的练习目录中创建仓库，结合 git status 观察每一步操作带来的变化。

## 如何使用

通过左侧章节目录选择内容，也可以使用正文底部的“上一章 / 下一章”按顺序阅读。左侧搜索框可以按标题筛选本册章节。
